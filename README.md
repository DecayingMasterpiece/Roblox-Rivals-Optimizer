## ✨ Features

- **⚡ Universal 1-Click Optimization**: Auto-detects your system hardware (CPU cores/threads, GPU, RAM) and applies safe, maximum-FPS configuration without system instability.
- **📶 Network Latency & Ping Stabilizer**: Disables Nagle's algorithm (`TcpNoDelay` & `TcpAckFrequency`) in the Windows registry, flushes DNS caches, and eliminates micro-stutters during network packets exchange.
- **🧼 Weekly Deep Junk Cleaner**: Safely scrubs DirectX Shader Cache, Windows Prefetch, and temporary files without touching personal data.
- **🎯 Roblox Rivals Curated FastFlags**: Pre-configured JSON presets tailored specifically for fast responsiveness, high FPS, and smooth mouse polling.
- **🛡️ 100% Anti-Cheat Safe**: Zero memory injection, zero DLL tampering. Fully compliant with Roblox Hyperion anti-cheat.

## 🚀 Quick Start Guide

1. Download **`Kai_Optimizer.zip`** from the [official website](https://decayingmasterpiece.github.io/Roblox-Rivals-Optimizer/) or from the repository releases.
2. Extract the ZIP folder to any directory (e.g. your Desktop or Downloads).
3. Right-click **`Launch.bat`** and click **Run as administrator** (if prompted).
4. Select **Simple Mode** and click **"Start Quick Optimization"**, or customize individual steps in **Advanced Mode**.
5. Launch **Roblox Rivals** and enjoy buttery-smooth performance!
